# Elementos separados del mockup de JJ Pega

Estos archivos se extrajeron de la referencia visual para que el diseño pueda montarse por capas sin convertir la página completa en una sola imagen.

- `header-logo.png`: logo del encabezado.
- `hero-copy.png`: titular y texto principal.
- `hero-illustration.png`: ilustración de los personajes con la hoja de stickers.
- `button-view-stickers.png` y `button-create-mine.png`: referencias visuales de los botones del hero.
- `category-individual.png`, `category-packs.png`, `category-custom.png`, `category-ai.png`: tarjetas de categorías.
- `sticker-*.png`: ocho piezas individuales del catálogo.

La navegación y los botones de compra continúan siendo HTML interactivo; los recortes ilustrados se usan como recursos visuales independientes.
